# 故障与恢复矩阵

| OLED/状态 | 条件 | 电机动作 | 恢复方式 |
|---|---|---|---|
| `IMU ERROR` | MPU身份、通信或DMP初始化失败 | 停止 | 检查接线后重新上电 |
| `EMERGENCY STOP` | PB21长按800 ms或离地保护触发 | 立即停止并锁存 | 松键、短按确认、重新完整标定 |
| `MOTOR OFF` | 传感器调试阶段或启动未完成 | 停止 | 完成本阶段/启动条件 |
| `DIR:REVERSE` | 电机命令与编码器符号不一致 | 测试脉冲后停止 | 修正对应motor/encoder sign |
| `MOVE:NO` | 测试PWM下无编码器变化 | 测试脉冲后停止 | 检查死区、供电、电机、编码器 |
| `LF:FAULT` | 循迹持续丢线 | 退出循迹，平衡保持 | 回到有效线路后按键重试 |
| `PROTECT:SHADOW` | 离地条件只观察 | 不因离地逻辑停机 | 收集数据并调整阈值 |
| `PROTECT:ON` | 离地条件持续达到确认时间 | 软件急停锁存 | 人工确认并重新标定 |
| 控制时序故障 | 超时、队列溢出、重复序号 | 停止并退出运行 | 自动总线恢复后重新标定 |
| 倾角超过35° | 小车倾倒 | 停止并退出运行 | 扶正后重新标定 |

本工程明确不包含硬件STBY急停和电池欠压检测。软件急停不能替代物理断电。
