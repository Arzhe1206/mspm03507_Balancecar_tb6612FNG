# 10 ms Control Loop

每个有效 MPU6050 数据就绪事件只生成一个控制帧，固定顺序如下：

1. 锁存帧序号和微秒时间戳。
2. 锁存左右编码器累计值和四路红外位图。
3. 读取 DMP FIFO，校验四元数并计算姿态。
4. 计算当前帧编码器增量。
5. 更新平衡 PD。
6. 在对应调试阶段开放速度 PI。
7. 在对应调试阶段开放 yaw/gyro Z 转向。
8. 循迹开启时生成受限航向和角速度目标。
9. 合成左右 PWM，限幅后一次性提交 TB6612。

异常帧不补跑历史 PID。短时异常允许基于上一有效角速度的受限预测；超过样本年龄、预测时长或连续异常阈值后锁存停机。
