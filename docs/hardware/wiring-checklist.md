# Wiring Checklist

- 断电检查左右电机与编码器接线，无短路和松脱。
- 确认 MPU6050 INT、I2C 电源、电平和地线。
- 确认红外只接 IO1～IO4，未把未使用输出接入控制输入。
- 确认 PB21 按键在上电前未被持续压住。
- 首次电机和编码器极性测试必须架空车轮。
- 当前没有硬件 STBY 和欠压检测，不得依赖软件替代电源级保护。
- 调试时使用限流电源，并保留人工断电手段。
